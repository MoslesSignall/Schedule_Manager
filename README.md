# 月历纸生成器

自动生成 A4 月历纸的 Windows 图形程序。

## 快速使用

1. 双击 **`dist\月历纸生成器.exe`**（单文件版）即可运行。
   - 若你的环境无法运行单文件版，可改用 **`dist\月历纸生成器_文件夹版\月历纸生成器.exe`**（文件夹版，功能完全相同）。
2. 左侧选择年份（2000–2099）、月份（1–12），右侧实时预览。
3. 点击 **“导出 PDF / PNG / JPG”** 生成 A4 月历纸（PDF 为 300 DPI 矢量尺寸页面）。

## 功能说明

- **表格结构**：7 行 × 8 列。第 1 行整行合并显示“年/月”；第 2 行为表头（周次 / 星期一…星期日 + 英文缩写）；第 3–7 行为本月日期。
- **周次规则**：星期一为一周开始；某年 1 月 1 日所在的星期记作该年第 1 周。
- **极端情况**：平年 2 月（4 周）第 5 行留空；跨 6 周的月份（如 1 日为周日）把末尾几天与首行合并，周次用斜杠表示（如 `31 / 36`）。
- **农历与节日**：自动计算农历日期；包含二十四节气、法定节假日（元旦/春节/清明/劳动节/端午/中秋/国庆）及重要节日（元宵节、妇女节、植树节、青年节、儿童节、建党节、建军节、七夕、中元节、教师节、重阳节、腊八节、小年、除夕、母亲节、父亲节等）。
- **个性化**：标题、表头中文/英文、周次、日期、农历、节日/节气、水印 8 个元素可分别设置字体（读取电脑全部字体）、颜色、字号、加粗；非等宽字体按全角/半角等宽排版。
- **背景水印**：可开关“月份英文简写”水印（1–12 月分别为 JAN…DEC，9 月为 SEP），可调透明度；也可自选图片作为背景并调节透明度。
- **默认月份**：打开时默认当前月；若已到本月最后一周则默认下月。

## 设置保存

设置保存在 `%APPDATA%\月历纸生成器\settings.json`（若不可写则保存到程序所在目录）。

## 从源码运行

依赖见 `vendor\` 目录（开发环境用）。入口为 `main.py`：

```
python main.py
```

打包（需安装 PyInstaller）：

```
python -m PyInstaller --noconfirm --onefile --windowed --name "月历纸生成器" --icon icon.ico --paths vendor --collect-all customtkinter main.py
```
